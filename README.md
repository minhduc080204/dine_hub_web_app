
# 🍽️ Dine Hub Web App

A Full-Stack Cross-Platform Shopping & Management Application for web, iOS, and Android, built with **Laravel**, **React Native**, **Docker**, and **MySQL**.

## 📚 Live Demo & Repository
- Repo: https://github.com/minhduc080204/dine_hub_web_app  
- Figma: https://www.figma.com/design/Kh2GvebWmmLc8jRs3e1NRB/DineHub--Restaurant-Food-Delivery-Figma-UI-Template

## 🚀 Project Overview

Dine Hub aims to provide a seamless shopping and management experience across multiple platforms. Users can:
- Browse and purchase products via **web**, **iOS**, or **Android**.
- Track orders and manage profile settings.
- For admins and shop owners: add, update, and remove products, monitor orders, and view analytics.

## 🧱 Key Features

### 🔹 Consumer App (React Native)
- Browse products by categories
- Search and filter items
- Cart management and checkout
- Profile and order history

### 🔹 Admin Dashboard (Laravel + Blade/API)
- Product CRUD operations
- Order management and status updates
- User management
- Reporting and analytics panels

### 🔹 Shared Core Features
- **User Authentication & Authorization** via Laravel Sanctum
- **RESTful APIs** for frontend-backend communication
- **Real-time updates** (e.g. order status)
- **Docker**-based development environment

## 🛠️ Tech Stack

| Layer            | Technologies                                                |
